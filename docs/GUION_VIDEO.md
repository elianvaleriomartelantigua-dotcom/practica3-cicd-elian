# Guion para video de presentación (4-6 minutos)

Graba pantalla y voz. Usa datos reales de tu repositorio. Puedes subir el video a YouTube según las indicaciones del profesor y copiar su enlace al informe.

1. **Presentación, 20 s.** “Soy Elian Valerio Marte Lantigua, matrícula 20240089. Presento la Práctica 3 de configuración básica de un pipeline CI/CD.” Muestra README y URL del repositorio público.
2. **Aplicación, 45 s.** Ejecuta npm start, crea una tarea, complétala y elimínala. Explica que DELETE y la validación de títulos son las mejoras.
3. **Pruebas, 50 s.** Muestra validarTitulo.js y nuevas.test.js. Ejecuta npm test. Explica prueba unitaria de límites y prueba de integración de eliminación. Muestra la cobertura real.
4. **Workflow, 60 s.** Abre ci.yml. Explica dependencias, sintaxis, Jest, Docker y Pages. Señala needs: build-test y la condición para desplegar.
5. **Rojo y verde, 60 s.** Abre la ejecución roja ya preparada: muestra la aserción modificada y el despliegue omitido. Luego muestra el commit de corrección y ambos jobs verdes.
6. **Página publicada, 45 s.** Abre la URL real de Pages. Crea y elimina tareas. Explica localStorage y que Pages no ejecuta Node.js.
7. **Cierre, 20 s.** Muestra CONTRIBUTING y el informe con los enlaces completados. “Las verificaciones se automatizan y el sitio se publica cuando los controles pasan.”

Antes de grabar: prepara las dos ejecuciones remotas, cierra información personal, verifica audio y completa el informe. No presentes los resultados locales como si fueran ejecuciones de GitHub.
